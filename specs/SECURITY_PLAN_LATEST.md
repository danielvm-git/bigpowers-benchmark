# Security Plan & Threat Model — BigPowers-Benchmark

Last updated: 2026-11-06. Generated by `security-review`.

## Threat Model (STRIDE)

| Threat Category | Potential Vector | Mitigation & Controls | Verification Status |
|---|---|---|:---:|
| **Spoofing** | Unauthorized access to model provider APIs | Credentials stored only in macOS Keychain (`SecItemAdd`), never in files or process environment. | PASS (`KeychainServiceTests` green) |
| **Tampering** | Agent modifying protected test suites during benchmark run | Worktrees are isolated and hashed; tamper detection flags any edit or deletion in protected test files. | PASS (`test_ab_score.py` green) |
| **Repudiation** | Mutated task or test definitions post-run | All runs record input SHA provenance, dirty status, and frozen task tree hashes. | PASS (`test_ab_provenance.py` green) |
| **Information Disclosure** | Leakage of API tokens in log streams or UI | `ShellCommandRunner` and `Logging` redact sensitive patterns; `.env*` files are strictly gitignored. | PASS (`LogSanitizerTests` green) |
| **Denial of Service** | Unbounded external process execution / infinite loops | Strict timeouts on all process launches (`timeoutMs`); container resource caps in Docker runner. | PASS (`test_ab_process_group.py` green) |
| **Elevation of Privilege** | Arbitrary code execution on host from untrusted model output | Benchmarks execute inside ephemeral Docker containers (`pi-docker`) with dropped capabilities. | PASS (`test_ab_sandbox.py` green) |

## Security Review Audit Summary

### 1. Authentication & Secrets Path
- **Audit Target**: `Sources/BigPowersBenchmarkKit/Services/KeychainService.swift`, `ProviderCredentialResolver.swift`
- **Finding**: Zero plaintext secrets stored on disk or logged. All keys queried strictly via Security framework API with `kSecClassGenericPassword`.
- **Verdict**: PASS (CWE-312 / CWE-522 mitigated).

### 2. Command Execution & Subprocess Boundaries
- **Audit Target**: `Sources/BigPowersBenchmarkKit/Runner/ShellCommandRunner.swift`, `scripts/lib/ab_process.py`
- **Finding**: Commands are executed with explicit argument arrays, dedicated process groups (`start_new_session=True`), and SIGKILL timeouts. No unsanitized string interpolations passed to raw shell.
- **Verdict**: PASS (CWE-78 mitigated).

### 3. File System & Deserialization
- **Audit Target**: `Sources/BigPowersBenchmarkKit/Store/BenchmarkStore.swift`, `scripts/lib/ab-eval.py`
- **Finding**: JSON shards decoded using type-safe `Codable` structs (`BenchRow.self`). YAML loaded with `yaml.safe_load`.
- **Verdict**: PASS (CWE-502 / CWE-22 mitigated).
