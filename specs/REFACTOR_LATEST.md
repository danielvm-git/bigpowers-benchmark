# Refactor Plan — Outcome A/B Harness Integration & Architecture Cleanliness

Last updated: 2026-11-06. Generated by `plan-refactor`.

## Problem Statement
The outcome A/B benchmark harness originally lived in the `bigpowers` skill catalog repository. This conflated the role of the methodology framework (skills catalog) with the benchmark evaluator (scoring application). Running evaluation required complex external path cross-referencing and risked mutating the evaluation benchmark during normal skill development.

## Solution
Relocate the complete A/B evaluation suite, tasks, arms, and python runners into `bigpowers-benchmark`. Wrap the execution within `BigPowersBenchmarkKit` using `ShellCommandRunner` and `AsyncStream` event channels so the macOS app serves as a native GUI cockpit over the harness, while retaining strict backward compatibility for CLI workflows.

## Invariant
All existing `BenchRow` records in `~/runs/data/` and historical A/B evaluation reports (`AB-*.yaml`) must remain bit-for-bit readable and uncorrupted. CLI invocation `bash scripts/run-ab-eval.sh --dry-run` must remain idempotent and pass without side effects.

## Commits

1. Relocate task suites and configs from external source to `benchmarks/ab/` → verify: `test -d benchmarks/ab/tasks && test -f benchmarks/ab/config.yaml`
2. Port python evaluation runner and scripts to `scripts/lib/` and `scripts/run-ab-eval.sh` → verify: `python3 -m py_compile scripts/lib/ab-eval.py scripts/lib/ab_metrics.py`
3. Port Python characterization tests into `Tests/` → verify: `python3 Tests/test_ab_eval.py && python3 Tests/test_ab_score.py`
4. Wire `BigPowersBenchmarkKit/Harness/` domain models and command bridges → verify: `swift test --filter HarnessCommandTests`
5. Wire SwiftUI views for Harness runner status in Mission Control → verify: `swift test --filter AppShellTests`
6. Clean up foreign planning artifacts into `specs/archive/legacy/` → verify: `test -d specs/archive/legacy`
7. Ensure clean preflight parity across Swift and Python suites → verify: `swift test && lefthook run pre-commit && swift build`
